# 図面・部材の照合と編集

このリポジトリのHTML版に、既存の案件画面を拡張する「図面・部材」タブを追加する。ユーザーが確認した表示案に基づく。

1. **目的**: 部材表の行と元図面の位置を同じ画面で照合し、寸法の根拠・計算・確認事項を読めるようにする。
2. **入力**: 解析済みの部材、元図面の識別情報、埋め込みPNG/JPEG、図面位置をまとめた `*.drawing-parts.json`。PDFからの新規解析をこのUIで自動実行するものではない。
3. **出力**: 左に部材一覧、中央にクリックできる図面番号、右に長さ・幅・厚み、数量、式・結果、取付方向、材料・接合・メモ。編集は案件に保存し、部材データとしてファイルにも保存できる。
4. **データ構造**: 既存案件に任意項目 `drawingParts: { schemaVersion: 1, bundles: [...] }` を追加する。bundleは `id / name / productionUnits / source / parts / views`。partは安定した `id / sourceIds / name / zone / qty / dims[3] / finish / joints / note`。dimensionは `display / result / formula / method / source / axis`。viewは `id / title / source / image / width / height / marks`。位置は画像内の0〜1の比率で保持し、画像から寸法を測定しない。
5. **自動計算**: 使用枚数×製作台数を総数とする。マーカーの個数を使用枚数へ加算しない。入力された数値式は四則演算・括弧だけを専用パーサーで計算し、コードを実行しない。不明な変数がある場合は式を残し、結果をnullとする。すべて数値になったときだけ3寸法を降順に並べ替え、根拠・式・取付方向も一緒に移す。
6. **手動変更**: 寸法・使用枚数・読取メモを変更できる。入力値は「編集値」「編集・寸法計算」「編集・変数式」として元図面の明記値から区別する。最初の編集で `original` に元の寸法・枚数・メモを保持する。部材選択を変える際の入力は、成立する場合は保存し、成立しない場合はエラーを示して選択変更を止める。
7. **既存機能への影響**: 照合用の編集は native unit の自動保存イベントから分離する。「元アプリの設計で開く」で、解析部材を既存のユニット・構成ツリー・部材編集へ取り込む。既存ユニットと材料は保持する。位置・方向が揃う部材を既存3Dへ表示し、材料構成・木目・3寸法が成立した部材だけを既存木取りへ渡す。詳しくは [設計への取込仕様](native-drawing-import.md)。
8. **保存互換**: 任意項目のない旧案件はそのまま開く。既存の `maProject:` 保存キー・バージョン・ユニット形式は変更しない。このリポジトリにはElectronおよび `*.ma-project.json` の保存処理がないため、Windows版の互換形式を推測して生成しない。図面・部材ファイルは別の種類として保存する。同じ元図面を再読込して保存済みの編集を上書きしない。
9. **Undo / Redo**: 案件・図面データ単位で編集を最大50回戻せる。部材寸法と対応するdesign配置・方向を同時に復元する。元の読取情報とは別に履歴を保持し、戻した結果も案件へ保存する。入力欄では標準のテキストUndoを保つ。履歴は当該セッション内、保存した編集・originalは再読込後も保持する。
10. **エラー処理**: 不正なJSON、形式・ID・台数・枚数・寸法・画像・位置・参照先、不正な数値式と0除算を拒否する。検証が終わるまで案件へ保存しない。画像は埋め込みPNG/JPEGのみとし、外部画像取得やSVGスクリプトを行わない。保存容量を超えた場合は保存エラーを表示し、成功として扱わない。
11. **テスト**: `npm test`。旧案件保護、未知寸法、数量、並べ替えと軸・出典保持、不正入力、コード実行防止、同一図面の再読込を検証する。`npm run test:browser` はPython PlaywrightとChromiumを使用し、合成テストデータで一覧と図面の双方からの選択、4マーカーと4枚、編集、再読込、Undo/Redo、ファイル保存、HTMLとして解釈しないメモ、狭い画面を検証する。実際の提供図面はローカルだけで別途同じ操作を確認する。

## 利用

案件を開き、「図面・部材」→「部材データを読み込む」でJSONを選ぶ。部材番号を選ぶと対応する図面へ移動する。図面の番号からも部材を選択できる。右側で変更を保存すると、同じ案件を開き直しても編集内容が残る。

「元アプリの設計で開く」で既存の設計画面へ移動する。部材を選ぶと、元の寸法編集・材料選択と、厚み・取付方向・XYZ位置・読取根拠を表示する。「元図面を開く」で対応するG番号へ戻る。再取込では保存済みの設計編集を保持するため、照合側の変更で設計側を上書きしない。

図面画像と座標を含むため、部材の一覧だけのExcel/CSVは直接入力として扱わない。元のPDFや提供案件データを公開リポジトリへ同梱せず、`private-examples/` はGit管理から除外する。
