# 既存ユニットへの図面部材取込

仕様: `docs/native-drawing-import.md`。ユーザーが指定した既存アプリへの反映を実施する。

1. 失敗するテストを追加する。図面部材が既存customParts/partsに入ること、旧ユニット不変、再取込で編集保護、枚数、未確定値、方向と位置が正しいことを確認する。
2. `assets/drawing-native-core.js` に既存保存形式への変換・安全な式評価・配置生成・木取りの問題判定を分離する。部材IDと図面のG番号を対応づける。
3. `index.html` の既存部材取得・正面/3D・厚み参照・保存/縮約・木取りへ取込部材を接続する。`assets/drawing-native-ui.js` は既存historyEditorの厚み・方向・位置・出典・Undo/Redoを担当する。
4. 既存の図面タブに「設計へ取り込む」「設計部材を開く」を追加する。図面入りHTMLは既存の設計画面で家具を開く。
5. 私用データに図面寸法に基づく位置式と出典を付ける。未確定の長さ・位置・材料は保留して全33行/41枚を既存部材一覧に保持する。
6. コア・ブラウザーテストを実行し、既存部材編集→材料設定→木取り→保存/再読込を確認する。実図面でも同じ経路を確認し、レビュー後にPRとローカルHTMLを更新する。
